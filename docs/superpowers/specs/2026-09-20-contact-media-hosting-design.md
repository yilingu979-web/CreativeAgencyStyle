# 联系表单与媒体托管设计

日期：2026-09-20

## 目标

让 koujikeji.com 在移动端稳定打开；四部作品点击后能播放；联系表单的完整提交送达 postmaster@koujikeji.com。项目描述字段不设前端或服务端字数上限。

## 架构

- 网站静态文件、预览视频和四部完整作品迁入阿里云 OSS 中国香港节点，使用 HTTPS 的自定义域名提供访问。
- 完整作品统一转为 Safari 兼容的 H.264/AAC MP4 文件；网站的作品数据改为 OSS 媒体地址。
- 联系表单继续通过 POST /api/contact 提交。该接口部署为独立的阿里云函数，不随 OSS 静态网站托管。
- 函数用阿里云邮件推送向 postmaster@koujikeji.com 发送包含姓名、品牌/公司、联系方式、完整项目描述和提交时间的邮件。
- 邮件服务凭据仅放在函数的环境变量中，不写入前端或 GitHub 仓库。

## 表单行为

- 姓名、品牌/公司和联系方式保留合理校验。
- 项目描述改为必填的多行文本，不设最大字数；函数仍以请求体大小限制保护服务。
- 提交成功只在邮件服务确认接收后显示“已收到，我们会尽快与你联系”；失败显示可重试提示。
- 保留隐藏蜜罐字段和一分钟内重复提交拦截。

## 域名与安全

- 主站保持 koujikeji.com。
- OSS 只公开网站及媒体文件；不公开发信凭据。
- 静态站通过 HTTPS 提供，函数仅允许来自 koujikeji.com 的跨域提交。
- 不把视频下载地址暴露为 GitHub Release 链接。

## 验收

1. 手机打开 https://koujikeji.com/ 并完整加载页面。
2. 四个作品在弹层中均可播放，Safari 不显示不可播放图标。
3. 项目描述可填写超过 10 个字并成功提交。
4. 使用测试资料提交后，postmaster@koujikeji.com 收到一封包含全部字段的邮件。
5. 邮件发送密钥不出现在浏览器网络请求、前端产物或 GitHub 代码中。
